# 后台使用手册（可视化内容管理系统）

> 页面：`http://localhost:8080/admin`
> 账号：`admin`　密码：`sunzhihao2026`（登录后在「系统 → 账号」里可改）
> 前提：本地服务在跑（项目目录执行 `npm start`）。GitHub Pages 是纯静态，后台只在本地 Node 模式可用。

## 1. 它是什么样的后台

打开就是一屏内容卡片，不是 JSON 输入框。左侧按类型分栏，右边是当前类型的全部条目：

- 项目、兴趣相册、工具、时间线、校园照片、联系方式、导航、分支、公告
- 站点信息、首屏、关于、AI 助手、设置（这 5 类各只有一条，点开直接改）
- 系统：账号、发布、备份、操作记录、媒体库

每张卡有封面、标题、摘要、更新时间和状态徽章：**公开（绿）/ 私密（黄）/ 草稿（灰）/ 回收站（红）**。
卡片底部四个动作：设为私密（或设为公开）、存草稿、编辑、删除；进回收站后变成「恢复 / 彻底删除」。

## 2. 三种可见性（重点）

编辑抽屉顶部有「访客可见性」三选一：

| 状态 | 访客看到什么 | 接口 / 静态导出 |
|---|---|---|
| 公开 | 完整内容 | 正常返回 |
| 私密 | 列表里一张锁卡（标题 +「该内容暂未公开」），详情页也只剩标题和这句 | 正文、图集、封面一律不返回；导出时该条引用的图片若没有别处在用，会一起剔出 `dist` |
| 草稿 | 什么都看不到，连标题都没有 | 完全不返回 |

说明：
- 私密是**接口层过滤**，不是前端藏起来，抓 `/api/content` 或 `dist/data/site.json` 都拿不到正文。
- 想给朋友看某条私密内容的完整效果，用抽屉里的「前台预览」——它签发 10 分钟一次性令牌，只有这个链接能看到全文，别人打开仍是占位。

## 3. 新增与编辑

1. 点右上「＋ 新建」→ 抽屉打开，填标题、摘要、封面、正文分节等。
2. 保存即写入 `data/site.json`，已打开的前台页面会通过 SSE 自动刷新；新条目默认「公开」，存完就能用 `#/work/<id>` 打开。
3. 正文区「正文分节」按 h（小标题）+ p（段落）逐行增删、上下移动；段落支持 Markdown（工具条可插入 H2、加粗、列表、链接）。
4. 图集逐行放图片地址，点「上传」直接从本机传图（png/jpg/webp/gif/avif，≤8MB）；封面同理。
5. 标签用逗号分隔；外链按「文字 + URL」成对增删。
6. Ctrl+S 保存；关闭抽屉若有未保存内容会二次确认，并把这部分留成本机草稿（5 秒自动写一次），下次打开可「恢复」或「丢弃」。整包 JSON 不会进 localStorage。

## 4. 排序、批量与回收站

- 直接拖动卡片换位；或选中卡片后 `Alt + ↑ / ↓`。顺序写入每条内容的 `order`，刷新不变。
- Ctrl/Cmd 点勾选框可多选，顶部出现批量条：设为公开 / 私密 / 草稿 / 移入回收站 / 取消选择。
- 删除是软删除：进回收站，正文与图片都留着，点「恢复」原样回来。回收站里再点「彻底删除」才会真正移除，**移除前自动备份 `data/backups/site-*.json`**。
- 「首页精选」单独管理：勾选最多 6 个公开项目，决定首页/经历页那四张主卡是谁。

## 5. 键位与移动端

- `Tab` 依次聚焦卡片，`Enter` 打开抽屉，`Esc` 关闭；开关用空格切换。
- `Ctrl+S` 保存当前抽屉。
- 390px 宽度下：左栏收成横向滚动的类型条，卡片单列，抽屉全屏，无横向滚动。

## 6. 系统页

- **账号**：改密码（当前密码 + 新密码 ≥8 位），成功后会话自动续期。
- **发布**：一键 `npm run build` + 推送 GitHub Pages，面板实时滚动构建/部署日志；失败会停在 error 并保留日志。
- **备份**：列出 `data/backups/site-*.json`，可一键恢复（恢复前会再备份当前状态）。
- **操作记录**：最近 100 条，谁 / 何时 / 对哪条 / 做了什么（create、update、visibility、reorder、trash、restore、purge、import…）。
- **媒体库**：`/uploads` 与 `/assets` 的图片，可复制地址；删除前确认没有内容引用。

## 7. 安全边界（已实现）

- 所有写接口要求登录 Cookie + `X-Requested-With: fetch`，并限速 60 次/分钟/IP；未登录 401，缺写请求头 403。
- 内容类型与字段都走白名单，不允许用请求参数拼任意 `site.json` 路径。
- 私密图片放在 `/uploads/private/` 时，没有后台会话或预览令牌直接 404。
- 后台资源与接口不进静态包；`dist` 里没有 `admin.js`。
- 登录失败 5 次锁 15 分钟；会话默认 4 小时（可在「设置」里改）。

## 8. 常见问题

**Q：线上 `sunzhihaoai.top/admin` 打不开？**
A：正常。线上是 GitHub Pages 纯静态，没有 Node 与写接口，后台只在本地 `http://localhost:8080/admin` 用。改完内容点「发布上线」，线上前台才会更新。

**Q：保存后前台没变？**
A：确认前台也是 `localhost:8080` 打开的；SSE 断线时刷新一次即可。

**Q：误删了内容？**
A：先去「回收站」恢复；彻底删除过的，到「系统 → 备份」选时间点恢复。

**Q：忘了密码？**
A：`npm run init -- admin 新密码` 重置，或改 `data/users.json` 前先备份。

## 9. 回滚这次改造

1. 把 `_backup\admin-<时间戳>\` 里的 6 个文件还原到原位（`data/site.json`、`src/routes/content.js`、`public/assets/js/admin.js`、`public/assets/css/admin.css`、`public/assets/js/app.js`、`scripts/export-static.js`）。
2. 删除新增文件：`src/content-filter.js`、`scripts/migrate-content.js`、`src/routes/publish.js`。
3. 回退 `server.js`（去掉 publish 挂载与私密图片鉴权）和 `src/store.js`（`saveContent` 的 meta 透传、`backupSite` 导出）的改动。
4. 重启 `npm start`。
