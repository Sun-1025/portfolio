# 后台使用手册

> 适用版本：2.0.0  
> 后台地址：`http://localhost:8080/admin`（局域网内把 `localhost` 换成服务器的内网 IP）

## 1. 登录与会话

1. 打开 `/admin`，输入管理员账号与密码。
2. 默认账号为 `admin` / `Admin@12345`，**首次登录后请立刻在「账号设置」里修改密码**。
3. 登录成功后，右上角会显示「会话剩余 xh xxm」。会话固定 4 小时，到时自动回到登录页。
4. 登录失败连续 5 次会触发 15 分钟限流；等待后重试即可。
5. 点击左下角「退出登录」可立即清除会话 Cookie。

> 安全说明：会话使用的是 HttpOnly Cookie，JavaScript 读不到 Token；不要把后台地址直接暴露到公网。

## 2. 保存逻辑

- 所有表单改动先进入浏览器内存，右上角出现「有未保存的修改」。
- 点「保存修改」才会写入 `data/site.json`，并通过 SSE 通知已打开的前台页面自动刷新。
- 点「放弃修改」会重新从服务器加载，丢掉本次未保存的改动。
- 每次保存都会在 `data/backups/` 自动生成一份备份，最多保留 30 份。
- 本地服务保存即生效；如果同时维护 GitHub Pages，需要再执行一次静态导出并推送。

## 3. 各标签页说明

### 3.1 概览

显示项目案例数、启用工具数、导航入口数、关于我段落数，以及服务/数据状态。快捷操作可直接跳到常用编辑页。

### 3.2 站点信息

| 字段 | 作用 |
|---|---|
| 品牌名 | 左上角 Logo 文字、页面标题前缀 |
| 浏览器标题 | SEO 标题 |
| 一句话签名 | 品牌副标题 / 首屏小字兜底 |
| SEO 描述 | 搜索引擎摘要 |
| 头像 | 首页肖像，建议 3:4 竖图、WebP、宽度 900px 左右 |
| 主题色 | 浏览器地址栏颜色 |
| 强调色 | 荧光黄绿强调色 |
| 页脚版权 | 底部版权文案 |

头像可以直接填 `/assets/...` 或 `/uploads/...`；也可以到「媒体库」上传后点「设为头像」。

### 3.3 导航与分支

- **顶部导航**：`显示文字`、`类型`、`目标`、`排序`、`是否显示`。
  - `route` 类型的目标填 `home` / `work` / `tools`。
  - `link` 类型的目标填 `/classic/` 或完整网址。
  - 排序数字越小越靠前。
- **站点分支**：`builtin`（内置页面）、`legacy`（旧版页面）、`custom`（自定义）。
  - 关闭「启用」后，前台顶部导航会隐藏对应入口；直接访问该分支路由会显示「分支暂时关闭」。
  - `classic` 分支对应 `/classic/` 静态页，不经过 SPA 路由。

> 导航和分支是两个开关：导航控制“入口是否出现”，分支控制“页面是否允许访问”。正式隐藏一个板块时，两处都要关闭。

### 3.4 首页内容

- **首屏 Hero**：上方小字、主标题、引导语、主/次按钮文字与链接。主标题里的回车会在前台保留换行。
- **数据条**：首屏下方四个关键数字，可增删。
- **关于我**：标题、副标题、正文段落（一行一段）。
- **个人档案**：键值对，例如「所在地 / 山东 · 东营」「主攻方向 / 嵌入式 · 物联网」。
- **能力介绍**：三张能力卡片的标题与正文。
- **技能标签**：名称 + 是否高亮。
- **个人理念**：多段文字 + 一句金句。
- **未来方向**：阶段标题与说明。
- **联系方式**：标签、显示值、链接（邮箱用 `mailto:`，网页用 `https://`）。

### 3.5 项目案例

1. 顶部标签选择要编辑的案例。
2. 可修改标题、分类、序号、归属、时间、角色、摘要、标签、配图、结果一句话。
3. 「正文小节」可增删，每个小节有小标题和正文。
4. 「外部链接」可增删，填写文字与 URL。
5. 删除案例不可撤销，但可以从「备份恢复」回滚。

配图地址一行一个，例如：

```
/assets/library-shot.webp
/uploads/2026-11-22-demo.webp
```

### 3.6 工具管理

- 每个工具包含：`ID`、`名称`、`图标`、`分类`、`简介`、`模块文件`、`排序`、`启用`。
- 关闭「启用」后，前台工具列表不再显示该工具。
- `模块文件` 必须与 `public/tools/` 下的文件名一致，例如 `markdown.js`。
- 新增工具的完整步骤见 [扩展开发指南](扩展开发指南.md)。

### 3.7 公告

- 首页只显示第一条「启用」的公告；没有启用公告时整块隐藏。
- 正文支持轻量标记：`**加粗**`、`` `行内代码` ``。
- 日期建议使用 `YYYY-MM-DD`。

### 3.8 媒体库

- 支持上传 `png / jpg / jpeg / webp / gif / avif`，单张不超过 8MB。
- 上传后可「复制地址」或「设为头像」。
- `assets` 目录是原站资源，只读；`uploads` 目录是后台上传，可删除。
- 出于安全考虑，**不再允许上传 SVG**。

### 3.9 备份恢复

- 每次保存自动生成备份，最多 30 份。
- 点「恢复到此版本」会把当前内容替换成该备份，并再生成一份恢复前的备份。
- 也可以手动复制 `data/site.json` 到其他磁盘做冷备份。

### 3.10 账号设置

- 修改密码需要当前密码 + 新密码（至少 8 位）+ 确认新密码。
- 修改成功后会重新签发会话，右上角倒计时重置。
- 退出登录后需要重新输入账号密码。

## 4. 常见问题

**Q：保存后前台没变化？**  
A：确认前台是通过 `http://localhost:8080` 打开的，并且没有被浏览器缓存成静态文件；硬刷新一次。SSE 断线时刷新页面即可。

**Q：上传图片失败？**  
A：检查格式是否在白名单内、是否超过 8MB；文件名不要带特殊符号。

**Q：后台打不开 / 一直转圈？**  
A：确认 `npm start` 仍在运行、8080 端口没有被占用；查看 `server.err.log`。

**Q：忘记管理员密码？**  
A：在项目目录执行 `npm run init -- admin 新密码（至少8位）` 重置密码，然后重新登录。操作前先备份 `data/site.json`。

**Q：想把站点恢复到昨天的状态？**  
A：后台「备份恢复」选择对应时间点；或直接把 `data/backups/site-....json` 复制回 `data/site.json` 后重启服务。

## 5. 发布到外网

本地保存只影响本地服务。要让 GitHub Pages / Cloudflare Pages 同步：

```powershell
npm run export
# 或子路径部署：
npm run export -- --base=/你的仓库名/
```

然后把 `dist/` 发布到静态主机。详细步骤见 [内网部署与访问加速](内网部署与访问加速.md)。
