# 模板选型记录

> 目标：给个人站选一套现代、响应式、轻量的 UI 外壳，同时保留经典版。  
> 结论：**采用“编辑式极简 + 轻玻璃顶栏 + 克制动效”的原生实现**，不直接套用某个模板的整包依赖；结构与组件参考下列开源模板和动效站。

## 1. 候选模板

| 模板 | 技术栈 | 许可 | 适合点 | 不适合点 |
|---|---|---|---|---|
| Astro Nano | Astro + Tailwind | MIT | 极简排版、作品集/博客结构、100/100 Lighthouse、响应式 | 需要 Astro 构建；视觉偏冷静，不够“炫” |
| Start Bootstrap Personal | Bootstrap 5 | MIT | 个人简历/作品集完整结构、Hero + 关于 + 履历 + 联系 | Bootstrap 体积与默认组件感偏重 |
| Tailwind Toolbox Profile-Card | HTML + CDN Tailwind | MIT | 单页个人档案、链接聚合、轻卡片 | 信息密度低，不适合多项目/工具站 |
| Motionsites.ai（Nomi / Zenith Realty 等） | 商业模板展示 | 仅参考 | 大字号、全屏动效、滚动节奏、深色高对比 | 商业模板，不能直接复制资产/代码；深色房产风与个人站内容不匹配 |

## 2. 最终落地方案

新版主站不是把某个模板原样搬过来，而是按以下映射实现：

| 来源 | 采用的部分 | 落地位置 |
|---|---|---|
| Astro Nano | 编辑式大标题、细分隔线、留白、单列阅读节奏 | Hero、About、Work 列表 |
| Start Bootstrap Personal | 个人档案 + 数据条 + 经历/项目 + 联系页脚的信息顺序 | 首页模块顺序 |
| Tailwind Toolbox Profile-Card | 轻卡片、圆角、头像框、简洁标签 | 项目卡、工具卡、技能标签 |
| Motionsites.ai | 滚动依次进场、首屏大标题的节奏、深色/浅色对比 | Hero 进场、区块 reveal |
| ReactBits Tilted Card | 卡片悬浮上浮 + 边缘高光的交互语言（当前实现为上浮，不做 3D 倾斜） | 项目卡 / 工具卡 hover |
| Aceternity Spotlight | 局部光斑/边缘高光，不铺满全屏 | 卡片 hover 光晕 |
| Uiverse.io | 玻璃按钮、细边框、hover 高光 | 主按钮 / 次按钮 |
| motion.dev | `transform` / `opacity` 的缓动曲线与 stagger 节奏 | 滚动 reveal、页面切换 |

## 3. 为什么不用 Tailwind 运行时

- 当前站点是 Express + 原生前端，页面少、组件少；挂 Tailwind CDN 会增加首屏请求与体积。
- 原生 CSS 变量已经能覆盖主题、玻璃、响应式；静态导出还能被 clean-css 压缩。
- 如果后续组件数量明显增加，建议改成 **构建期 Tailwind**（Vite/PostCSS），而不是 CDN 运行时。

## 4. 玻璃与低饱和规则

- 顶栏：`backdrop-filter: blur(18px) saturate(1.1)`，滚动后加细底边；只在导航层使用，不把整页做成玻璃。
- 卡片：白底/暖纸底 + 1px 细边 + hover 光晕；不使用高饱和渐变、霓虹描边、塑料高光。
- 强调色：`#cdd96b` 荧光黄绿，只用于关键按钮/高亮标签，面积不超过页面的 10%。
- 文字：深墨 `#12110b` + 次级灰；大标题用衬线，正文用无衬线，标签用等宽字体。
- 动效：默认 420ms、`cubic-bezier(.22,1,.36,1)`；只动 `transform/opacity`；`prefers-reduced-motion` 下全部关闭。

## 5. 保留的旧版

- 经典版：`public/classic/index.html`，原 3D 黑板场景页，完整保留，入口在顶部导航「经典版」。
- 新旧两套 UI 共用 `data/site.json`；经典版通过 `fetch('/data/site.json')` 读取后台内容。
- 后台保存后，新版通过 SSE 自动刷新；经典版刷新页面后读取最新数据。

## 6. 后续可升级方向

1. 把项目卡 hover 升级为真正的 3D tilt（参考 ReactBits Tilted Card），但只在桌面端启用。
2. 给 Hero 肖像加极轻的视差/光斑，不改变人物本身的动效风格。
3. 用 View Transitions API 做路由切换，保留 `prefers-reduced-motion` 降级。
4. 如果要做深色“炫酷”版，另开 `#/stage` 分支，不影响当前低饱和主站。
