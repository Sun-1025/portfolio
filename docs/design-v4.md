# 个人站点 v4 · 设计说明

## 一、方向

站点保留“终端 / 控制室”的核心识别，但不再用一套很细的 HUD 小字来撑密度。v4 的方向是：

**工程仪表 + 编辑式排版。**

- 仪表：顶栏、状态条、项目索引、信号核心、终端日志，仍然有明确的读数和状态。
- 编辑：标题、导语、项目叙述、自述按阅读节奏排，不把每段话塞进面板。
- 色彩：深空近黑 + 酸性信号绿 + 冰青，饱和度整体下调，避免荧光塑料感。
- 字体：`IBM Plex Sans` + `IBM Plex Mono` + `Noto Sans SC`，不使用 Inter / Space Grotesk。

## 二、设计 token

| Token | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#070908` | `#f1f0e7` | 页面底色 |
| `--bg-2` | `#0a0d0b` | `#e9e8de` | 区块交替底色 |
| `--surface` | `#0d1210` | `#fbfaf3` | 面板、卡片 |
| `--surface-2` | `#111814` | `#f4f3ea` | 浮层、输入区 |
| `--ink` | `#f1f4eb` | `#0b120e` | 主文字 |
| `--ink-2` | `#c4cec5` | `#35423a` | 正文 |
| `--muted` | `#94a298` | `#66756b` | 辅助文字 |
| `--accent` | `#d6f36a` | `#5c7900` | 信号绿 / 主操作 |
| `--accent-2` | `#7ce9d5` | `#087c72` | 冰青 / 状态与链接 |
| `--line` | 13% 米白 | 13% 墨色 | 分隔线 |

规则：

- 一个系统、一个主色。信号绿只用于主操作、当前状态、关键数字和少量强调。
- 冰青只做辅助状态、链接、次级标记，不与信号绿抢主色。
- 浅色主题不是简单反色：底色偏暖纸白，信号绿压到 `#5c7900`，保证白底上的对比度。

## 三、字体层级

六级信息层级 + 一个首页展示级。展示级只用于首页 Hero，不参与正文层级；其余六级覆盖所有内容页与板块。

| 角色 | 字号 | 行高 | 字重 | 使用位置 |
| --- | --- | --- | --- | --- |
| Hero 展示级（特殊） | 66–82px（随视口） | 1.08 | 600 | 首页主标题 |
| 内容 H1 | 38–54px | 1.12 | 600 | 项目详情标题 |
| 板块标题 H2 | 40–46px | 1.14 | 600 | 各板块标题 |
| 条目标题 H3 | 24–31px | 1.2–1.4 | 600 | 项目、实践、兴趣 |
| 正文 | 16.5–18px | 1.72–1.9 | 400 | 段落、项目描述 |
| 辅助说明 | 14–14.5px | 1.75–1.8 | 400 | 面板说明、项目摘要 |
| 标签 / 小字 | 12–13px | 1.5 | 400–500 | 状态、编号、标签、页脚 |

实测：

- 1440 宽：正文 16.5px，导航 16.5px / 500，Hero 66.24px，板块标题 40px。
- 1920 宽：正文 17px，Hero 71px，板块标题 40px。
- 2560 宽：正文 18px，Hero 81.92px，板块标题 46px。
- 390 宽：Hero 41.34px，板块标题 33.54px，正文 16.5px。
- 全站最小字号 12px；首页、项目、详情、工具四条路由均无 12px 以下文本。

## 四、导航栏

| 参数 | 值 |
| --- | --- |
| 桌面高度 | 72px |
| 移动高度 | 62px |
| 横向内边距 | 与内容最大宽度自动对齐（1440 屏约 60px，1920 屏 240px，2K 400px） |
| 菜单字号 | 16.5px / 500 |
| 菜单点击高度 | 48.7–50.4px |
| 操作按钮 | 44×44px |
| 品牌方块 | 42×42px |
| 选中态 | 浅信号绿底 + 1px 边框 + 信号绿文字 |
| 悬停态 | 面板色底 + 常规边框 + 主文字 |
| 移动菜单 | 全宽下拉，行高 48px，菜单文字 15.5px |

顶栏使用 `backdrop-filter: blur(22px) saturate(160%)`，滚动时提高背景不透明度并加深阴影。主内容、品牌和导航右侧对齐同一 `--wrap-max`，解决超宽屏上“顶栏贴边、内容居中”的错位。

## 五、布局

| 视口 | 内容最大宽度 | 页面边距 |
| --- | --- | --- |
| ≤1699px | 1320px | 随视口 24–80px |
| ≥1700px | 1440px | 自动居中 |
| ≥2300px | 1760px | 自动居中 |

- Hero：左文右图，`1.16fr / 0.84fr`，右侧信号核心最大 560px。
- 项目索引：300px 封面 + 正文 + 48px 箭头；移动端改为纵向。
- 实践 / 关于 / 兴趣：左主栏 + 右侧粘性面板，980px 以下堆叠。
- 项目列表：桌面两列，首个项目横跨两列；移动端单列。
- 详情：正文 + 320px 侧栏；封面最大 920px、2.2:1，移动端 4:3。
- 页脚：大标题 + 四行联系方式；移动端单列。

## 六、插画

### Hero

- `public/assets/signal-core.webp`，1200×1500，66KB。
- 磨砂玻璃方块 + 内部信号折线 + 冰青脉冲点 + 细金属轨道。
- 对应站点“信号 / 端侧 / 嵌入式”的主题，不再使用动漫身份照作为首页主视觉。

### 项目封面

- `cover-voice.webp`：磨砂玻璃房屋、内部声波折线与冰青脉冲点。
- `cover-library.webp`：磨砂玻璃书页叠成的数据库圆柱，书页间透出数据行。
- `cover-physics.webp`：磨砂玻璃三棱镜、三道冰青光束与悬浮玻璃气球。
- 统一 1200×800、3:2 横版；同一深色摄影棚、同一磨砂玻璃材质、酸性绿主光 + 冰青辅光。
- 单张 20–43KB；在 300px 宽的索引封面和 920px 宽的详情横幅上都能看清主体。
- 项目封面不再使用细线稿。线稿在 300px 宽的缩略图上会掉到 1px 以下，无法承担“插画质感”。

## 七、AI 助手 Logo

### 图形

- 64×64 网格，外框 47×47、圆角 13.5。
- 中央是终端提示符 `>`，由两段 2.6px 圆头线组成。
- 右上角冰青脉冲点，底部一条信号弧线，左侧两条短刻度。
- 语义：终端 + 信号 + 在线状态，不卡通、不拟人。

### 规格

| 场景 | 尺寸 |
| --- | --- |
| 桌面浮标 | 56×56px |
| 悬停 | 放大 1.03，状态环透明度提高 |
| 面板头部 | 22×22px |
| 移动端 | 56×56px |

- 浮标带 conic-gradient 状态环，7 秒旋转，`prefers-reduced-motion` 下停止。
- 面板宽 420px，桌面距底部 72px；移动端为底部抽屉。
- 深色：`ai-logo.svg`；浅色：`ai-logo-light.svg`。
- 两个 SVG 均支持 `--ai-primary` / `--ai-secondary` 覆盖颜色，默认值分别为深色信号绿 / 冰青，浅色为压暗绿 / 深青。

## 八、动效与可访问性

- 仅保留三类动效：扫描线、状态环、悬停位移；全部在 `prefers-reduced-motion: reduce` 下关闭。
- 所有交互元素有 `:focus-visible` 2px 冰青描边。
- 跳过导航链接 `跳到主要内容`。
- 页面仅一个 H1；项目详情、工具页各一个 H1。
- AI 面板 `role="dialog"`，`aria-expanded` 随开关同步。
- 浅色主题下正文对比度 ≥ 7:1，辅助文字 ≥ 4.5:1。

## 九、性能

- 新增主视觉 66KB WebP；三个项目封面合计约 86KB；AI Logo 两个文件合计约 1.9KB。
- 不引入新 JS 框架；Tailwind 只输出 theme/utilities，约 8.3KB，不含 preflight。
- 项目封面与 Hero 使用 `loading="lazy"` / `fetchpriority` 区分优先级。
- 字体仍走 Google Fonts，保留系统回退；离线时版面不依赖网络字体。
