# 测试与验收

## 1. 验收原则

1. **先量测，再判断**：不靠“看起来还行”，用 DOM 矩形、计算样式、截图和性能数据。
2. **默认态不能被特性态污染**：浅色、深色、降级态都单独测。
3. **内容优先**：WebGL/字体/动画失效时，页面仍可读、可导航。
4. **可回滚**：每个阶段的备份都在 `_backup/`，测试发现回退时能原样恢复。

## 2. 测试矩阵

| 维度 | 覆盖 |
|---|---|
| 桌面 | 1440×900、1920×1080、2560×1440 |
| 移动 | 390×844、320×568 |

| 安全 | 未登录访问后台、上传非法类型、私密内容是否进入静态导出 |

## 5. 手动验收清单

### 首页 / 背景

- 首屏可见 Threads 线束，深色为白线，浅色为深线。
- 指针移动时线束跟随，离开后约 780ms 回中。
- 卡片 hover 时线束仍能从卡面透出，不被磨砂糊平。
- WebGL2 不可用时恢复 `.site-grid`，不出现黑屏。
- 页面隐藏时暂停渲染；`prefers-reduced-motion` 不播放动态背景。

### 回到顶部

- 向下滚动后出现，圆形按钮可点击。
- hover 展开为 `Back to Top`，文字在按钮内水平、垂直居中。
- 回到顶部后按钮隐藏。

### 关于页

- 左侧主栏与右侧信息栏顶部不必齐平，但信息栏在右侧垂直居中。
- 移动端堆叠后信息栏回到正常文档流，不出现重叠。

### 工具箱

- 列表和详情都能打开。
- 工具台左右两栏等高；右侧空队列区不会留下断裂的空白。
- 移动端改为单列，左右面板按顺序堆叠。
- 转换文件只在浏览器本地处理，不上传服务器。

### Agent

- 气泡文案为“我是此站 Agent，有什么问题都可以问我”，第二行有波浪下划线。
- 气泡不遮挡主按钮；打开面板后自动隐藏。
- 没有配置 AI 后端时，面板显示友好提示，不抛红字。
- 只有一处 `pointermove` 监听；指针离开用 `p.x === -9999` 判定。

### 后台

- 未登录访问 `/admin` 会进入登录页，不暴露内容。
- 登录后可编辑、排序、切换可见性、恢复、彻底删除。
- 私密内容不会出现在公开 API 和 `dist`。
- 保存后前台通过 SSE 刷新。
- “发布上线”能触发构建和 Pages 推送。

## 6. 已知边界

- 后台是单管理员、桌面优先；移动端只保证可打开，不保证完整编辑体验。
- JSON 文件适合小规模内容；多人并发写入需要数据库或锁。
- 静态版没有服务端；留言、后台、发布都不可用。
- AI 依赖上游模型服务，网络或配额异常时会走保底文案。
- 第三方字体/图标可能因网络失败；页面已准备系统字体回退。
- 截图和测试脚本是本地 QA 产物，不进入仓库。

## 7. 复现建议

如果需要重新跑一轮：

1. `npm start` 或静态服务器启动 `dist`。
2. 用 Edge/Chromium 打开 1440×900、390×844。
3. 按本文件的清单逐项截图。
4. 记录 DOM 矩形、计算样式、rAF 时间和控制台错误。
5. 把结果写回 `_shots/<stage>/results.json`（本地，不提交）。
