# 个人站点 v4 · 视觉与可用性巡检

- 站点：`https://sunzhihaoai.top`
- 本地对照：`http://localhost:8080`
- 巡检日期：2026-11-23
- 巡检尺寸：1440×1000、1920×1080、2560×1440、390×844
- 工具：Microsoft Edge 158 + Playwright / CDP 计算样式、全页截图、控制台与 404 监听

## 一、旧版实测基线

| 项目 | 旧版实测 | 问题判断 |
| --- | --- | --- |
| 顶栏高度 | 75.99px | 高度不低，但内部文字与图标偏小，显得空、弱 |
| 导航菜单文字 | 10px / 行高 16px | 远低于桌面端可读下限，视觉权重接近注释 |
| 正文 | 15px | 中文长文偏紧，阅读负担高 |
| Hero 主标题 | 107.5px | 字号很大，但与 10px 导航形成断层，层级不成体系 |

| 右下角 AI 入口 | 52×52px，单个 `>` 字符 | 有尺寸但无识别度，像临时占位 |
| 旧 CSS 小字分布 | 8px × 39、9px × 24、10px × 13、11px × 7 | 大量标签依赖 8–10px，属于系统性偏小，不是单点问题 |

## 二、问题清单

### 1. 字体系统

- 导航 10px、正文 15px、辅助标签 8–10px，层级压缩在一起，远看只剩标题和一片小字。
- 8px 在 1080P 与 2K 屏幕上都不适合作为信息标签；抗锯齿后笔画发虚，中文尤其明显。
- 中英文混排没有统一的中文回退策略，等宽字体只承担装饰，不承担信息。
- 行高偏紧，长段落与折叠面板里的说明文字容易挤成块。
- 明暗主题都依赖同一套低对比辅助色，浅色主题下小字更容易发灰。

### 2. 导航菜单栏

- 旧版操作按钮 36×36px，未达到 44px 的桌面点击舒适区。
- 导航项没有明确的 selected / hover 容器，只有文字颜色变化，层级弱。
- 顶栏虽然使用毛玻璃，但分隔线、阴影和滚动状态没有形成稳定的“仪表框”存在感。
- Logo 方块 36px，与 10px 菜单文字一起压缩了品牌区。
- 移动端菜单展开后字号仍偏小，点击行高不足。

### 3. 插图与插画

- 旧首页以奶白底 3D 动漫身份照为主视觉，与深色 HUD、终端日志、信号绿并置，风格割裂。
- 项目图多为场景截图或旧插画，缺少统一的画幅、线宽、色彩和网格语言。
- 插画在不同板块被拉伸，细节密度随容器变化，300px 宽时线稿几乎不可见。
- 装饰图标线宽、圆角、端点不统一，像从不同图标库拼在一起。

### 4. 右下角 AI 助手

- 旧入口是一个 52px 圆形里的单个 `>` 字符，没有品牌记忆点。
- 没有悬停动效、没有状态环、没有和站点信号色建立关系。
- 面板头部、消息标签、快捷问题仍在使用 9–10px 字号，与“AI 助手”这一主要功能不匹配。

## 四、巡检后落地的改动

- 建立 6 级字体层级，正文、辅助、标签分别落在 16.5 / 14 / 12–13px，不再靠 8px 撑信息密度。
- 导航文字提升到 16.5px，操作按钮统一 44px，桌面栏高 72px，移动端 62px。
- 主视觉改为磨砂玻璃信号核心 `signal-core.webp`，三个项目统一为同款深色摄影棚 + 磨砂玻璃 3D 封面。
- 三个项目封面统一 1200×800、3:2 画幅、同一套灯光与材质；单张 20–43KB，在 300px 索引行和 920px 详情横幅上都能看清主体。
- AI 入口改为“终端提示符 + 信号脉冲”标记，56px，带状态环、悬停放大与点击反馈；面板同步放大字号。
- 全站建立 12px 下限；1920 / 1440 / 390 三档 × 首页、项目、详情、工具四条路由，叶子文本扫描均为 0 处 <12px。
- 所有路由、主题切换、工具模块、AI 面板和后台上游逻辑保持不变。
