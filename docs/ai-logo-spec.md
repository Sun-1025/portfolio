# AI 助手 Logo 使用规范

## 一、设计概念

“终端提示符 + 信号脉冲”。

- 外框：圆角方形终端窗口，保留站点面板的直角仪表感。
- 中央：`>` 提示符，指向右侧，表示对话继续。
- 右上：冰青脉冲点，表示在线与信号。
- 底部：一条信号弧线，连接“输入 → 响应”的动作。
- 左侧：两条短刻度，来自终端行号与工程刻度。

不采用机器人头像、聊天气泡笑脸、卡通吉祥物。这个入口首先是一个“可执行的终端”，其次才是 AI。

## 二、网格与比例

- 画布：64×64。
- 外框：x=8.5，y=8.5，47×47，圆角 13.5。
- 提示符：从 (23,22.5) 到 (35.5,32)，再回到 (23,41.5)；线宽 2.6，圆头。
- 脉冲点：圆心 (45.5,18.5)，半径 3.2，渐变填充。
- 底部弧线：从 (18,50.5) 到 (47,48.5)，线宽 1。
- 左侧刻度：x=14–21，y=18.5 / 24，线宽 1。

安全边距：图形最外沿距画布 8.5，缩放时保留至少 8% 的空白。

## 三、颜色

| 变量 | 深色主题 | 浅色主题 | 用途 |
| --- | --- | --- | --- |
| `--ai-primary` | `#d6f36a` | `#546f00` | 外框、提示符 |
| `--ai-secondary` | `#7ce9d5` | `#087c72` | 脉冲点、信号弧线、刻度 |

- SVG 内所有颜色均通过 CSS 变量传入，可在页面、暗色/亮色主题或品牌换色时覆盖。
- 渐变 `pulse` 的两端也使用变量，不写死十六进制。
- 深色主题下外框透明度 0.42，提示符不透明；浅色主题下保持同样透明度关系，避免在白底上过重。

## 四、文件

| 文件 | 用途 |
| --- | --- |
| `public/assets/ai-logo.svg` | 深色主题浮标、面板头部 |
| `public/assets/ai-logo-light.svg` | 浅色主题浮标、面板头部 |

两个文件都是 64×64 viewBox 的独立 SVG，可直接嵌入 `<img>`、内联 `<svg>` 或作为 favicon 源。

## 五、尺寸

| 场景 | 尺寸 | 说明 |
| --- | --- | --- |
| 桌面浮标 | 56×56px | 默认 |
| 浮标悬停 | 57.7×57.7px | 约 1.03 倍，不改变布局 |
| 面板头部 | 22×22px | 与标题同一行 |
| 移动端浮标 | 56×56px | 右下角，避让安全区 |
| favicon | 32×32px | 使用独立 `favicon.svg`，不是直接缩 64px 版本 |

最小使用尺寸 24×24px；低于 24px 时只保留外框、提示符和脉冲点，去掉底部弧线与刻度。

## 六、动效

- 浮标外圈是 conic-gradient 状态环，7 秒一圈，透明度 0.55。
- 悬停：整体放大 1.03，状态环透明度升到 0.8，图标亮度提升 8%。
- 点击：缩放 0.97，120ms 回弹。
- `prefers-reduced-motion: reduce` 下停止旋转与缩放，仅保留颜色变化。

## 七、使用规则

**可以**

- 放在右下角固定入口、AI 面板头部、关于页的“AI 助手”说明块。
- 单色使用：只覆盖 `--ai-primary`，`--ai-secondary` 继承主色或保持冰青。
- 在深色底上用深色版，在浅色底上用浅色版。

**不要**

- 不要拉伸、压扁、旋转超过 8°。
- 不要加投影、外发光描边、彩色渐变底、卡通眼睛或嘴。
- 不要把 `>` 换成 `$`、`#`、`//` 等其他符号；提示符是识别核心。
- 不要在 24px 以下保留底部弧线与刻度。
- 不要把 Logo 放在图片或视频画面上作为水印。

## 八、可访问性

- 浮标 `aria-label="打开 AI 助手"`，`aria-expanded` 与面板状态同步。
- 面板 `role="dialog"`，标题为“孙志昊的 AI 助手”。
- 浮标焦点态为 2px 冰青外描边，偏移 3px。
- 深浅主题下图形与底色对比度均 ≥ 3:1；文字标签不依赖图形传达状态。
