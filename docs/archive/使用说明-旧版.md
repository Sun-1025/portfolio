# 个人作品集 · 使用说明

本文件配合 `index.html` 使用。网站为单文件、零依赖、零安装，双击即可在浏览器打开。

---

## 一、部署成在线链接

### 方案 A：GitHub Pages（国际通用，面试官最熟悉）

1. 打开 `github.com`，注册或登录账号（用户名建议用拼音，如 `sunzhihao`）。
2. 右上角 `+` → `New repository`：
   - Repository name：`portfolio`
   - 选 **Public**
   - 勾选 `Add a README file` → 点 `Create repository`
3. 进入仓库，点 `Add file` → `Upload files`，把 `index.html` 拖进去，提交。
   - 如果想让"下载简历 PDF"按钮可用，把简历 PDF 一起传上来，并重命名为 `孙志昊-简历.pdf`。
4. 仓库页 → `Settings` → 左侧 `Pages`：
   - `Source` 选 `Deploy from a branch`
   - `Branch` 选 `main`，目录选 `/ (root)` → `Save`
5. 等 1–2 分钟，刷新 `Settings → Pages` 页面，顶部出现你的网址，形如：
   `https://sunzhihao.github.io/portfolio/`

> 国内访问 GitHub Pages 有时较慢，但面试官打开通常没问题。

### 方案 B：Gitee Pages（国内直连，速度快）

1. 打开 `gitee.com`，登录已有账号（`SunZHAO1025`），确保已完成**实名认证**。
2. `+` → `新建仓库`，名称 `portfolio`，选 **开源**，勾选「初始化仓库」。
3. 上传 `index.html`（和简历 PDF）。
4. 仓库页顶部 → `服务` → `Gitee Pages` → 分支选 `master` → `启动`。
5. 部署成功后拿到网址，形如 `https://sunzhihao.gitee.io/portfolio`。

> 注意：Gitee Pages 每次修改内容后需要手动点「更新」重新部署。

### 拿到链接后

把这个网址填进简历页眉，或放在腾讯/小米表单的「个人主页链接」栏。同时记得把网站里 Hero 区的「访问代码仓库」按钮指向你的 Gitee 仓库（默认已设为 `gitee.com/SunZHAO1025`）。

## 三、后续修改维护指南

所有内容都在 `index.html` 内部的 `DATA` 对象里，**改数据不改代码**。打开文件搜索 `const DATA = {` 就能定位。

### 1. 改个人信息

找到 `DATA.profile`：

```js
profile: {
  name: '孙志昊',                          // 姓名
  typedLines: ['物联网工程 · 嵌入式开发方向'],  // 首屏打字机文案，可写多行轮流播放
  location: '山东东营 / 河北承德',
  school: '山东石油化工学院 · 物联网工程（大二在读）',
  status: '正在寻找软件开发 / 嵌入式方向实习',
  email: '1322816531@qq.com',
  wechat: 'chgh740905',
  giteeProfile: 'https://gitee.com/SunZHAO1025',   // 「访问代码仓库」按钮指向
  resumeUrl: './孙志昊-简历.pdf',                  // 简历 PDF 放同目录，改这里即可
  intro: ['第一段简介', '第二段简介'],              // 数组每一项是一段
  roles: ['校科协项目管理部部长']
}
```

### 2. 换主题色

搜索 `tailwind.config`，改这两行：

```js
colors: {
  primary: '#165DFF',       // 主色，改成你想要的颜色
  'primary-dark': '#0E42D2' // 主色加深版，用于 hover
}
```

改完后全站按钮、图标、进度条、雷达图会一起变。雷达图颜色是写死的，再搜 `rgba(22, 93, 255` 和 `#165DFF` 把它换成新色值即可。

圆角和阴影同理，在 `borderRadius` 和 `boxShadow` 里改。

### 3. 新增一个项目

找到 `DATA.projects` 数组，复制一个对象、粘在数组末尾，改内容：

```js
{
  icon: 'fa-solid fa-code',          // Font Awesome 图标名
  title: '项目名称',
  subtitle: '一句话定位 · 你的角色',
  time: '2026.12',
  desc: '两三句话讲清楚做了什么、用了什么技术、结果如何。',
  tags: ['技术栈1', '技术栈2'],
  highlights: ['亮点1', '亮点2', '亮点3'],
  link: 'https://...',               // 没有链接就留空字符串
  linkText: '查看源码'
}
```

保存刷新，卡片自动出现，排版自适应。

### 4. 新增一条经历

找到 `DATA.experiences`，复制一项：

```js
{
  time: '2026.12 – 至今',
  title: '职务或项目名称',
  org: '所属单位 / 角色',
  desc: '做了什么、做到什么程度，尽量带数字。'
}
```

数组顺序就是页面从上到下的顺序，把最新的放最前面。

### 5. 新增一项技能

找到 `DATA.skills`，复制一项：

```js
{ name: '技能名', level: 70, note: '一句话说明你用它做过什么' }
```

`level` 填 0–100，进度条会自动按这个比例生长。

### 6. 改统计数据卡片

找到 `DATA.stats`，改 `value`（数字）和 `suffix`（加号之类的单位符号）。

### 7. 启用预留的扩展模块

文件里有一个默认隐藏的板块，搜索 `id="extra"`，把这一行：

```html
<section id="extra" class="hidden py-20 sm:py-28 bg-white border-b border-line">
```

改成（删掉 `hidden`）：

```html
<section id="extra" class="py-20 sm:py-28 bg-white border-b border-line">
```

然后把里面的「自定义板块」标题和卡片内容换成你要的（获奖证书、博客文章、作品展示）。卡片可以复制多份，网格会自动排。

如果想让导航栏也能跳到这里，在导航区加一行锚点，或在 `DATA` 外直接改：

```html
<a href="#extra" class="nav-link px-3 py-2 rounded-btn text-body hover:text-primary hover:bg-primary-soft transition">更多</a>
```

## 四、常见问题

**Q：打开后样式全没了，页面很丑？**
A：Tailwind 走的是官方 CDN（`cdn.tailwindcss.com`）。断网或该域名不稳定时会加载失败。连上网重新打开即可。

**Q：图表、打字机、数字滚动不动？**
A：Chart.js / AOS / Typed.js / CountUp.js 都是从 jsDelivr 加载，需要联网。断网时页面文字内容仍然正常显示，只是没有动效。

**Q：想换头像，用真人照片？**
A：「关于我」左侧目前是一个渐变色圆形字母标识。把照片放到同目录（如 `avatar.jpg`），找到这段：

```html
<div class="w-16 h-16 rounded-full bg-gradient-to-br from-primary to-[#6AA0FF] ...">S</div>
```

替换成：

```html
<img src="avatar.jpg" alt="孙志昊" class="w-28 h-28 rounded-full object-cover border border-line shadow-lift mb-7" />
```

注意：图片放进单文件后，"零依赖"就不成立了，部署时记得把图片一起上传。

**Q：改了内容但页面没变？**
A：浏览器缓存。按 `Ctrl + F5` 强制刷新。
