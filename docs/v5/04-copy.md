- 不写「精通 / 顶级 / 神级 / 行业领先 / 颠覆 / 赋能 / 闭环 / 打造生态 / 极致体验 / 震撼 / 绝美」。
- 不写「不是……而是……」「在这个……的时代」「真正重要的是」。
- 项目数字和外部链接只保留可验证的事实；理财截图不公开，页面不写金额与收益率。
