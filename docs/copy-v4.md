- 先写具体做过什么，再写怎么想。少用形容词，多用动作、数量、结果。

- 不虚构奖项、论文、公司履历、团队规模和技术能力。

### WORKING NOTES

**01 / PLAN · DO · DONE**

> 把今天能动手的那一步先做掉。
>
> 计划拆到今天能动手；做的时候只看眼前这一步；做完留个结果，哪怕结果是「失败了，原因是这个」。

**02 / 结硬寨，打呆仗**

> 难事先扎住，再一点点啃。
>
> 不指望一次想明白所有事。先把能验证的部分做出来，再回头改。

**03 / 交付前先当最不讲理的用户**

> 输入空的、编号重复、文件坏了，都先自己试一遍。
>
> 系统能跑不算完，得顶住真实场景里的坏输入和断线。

## 七、关于我的完整自述

1. 我叫孙志昊，2005 年 11 月生，河北承德人，现在在山东石油化工学院读物联网工程，2025 级，大二。承德出门多是坡，东营的路平得能望到头，刚来那阵我骑车总想提前刹车。待了两个月，我反倒喜欢这种平，脚一蹬就能一直往前。

2. 性格测试说我是 ENTJ，我承认自己急。事情卡在那儿，我会一直惦记；进度没动，我就忍不住去催。这股急劲把一些事推成了，也让我得罪过人。后来我学着把语速放慢，先听完对方卡在哪，再谈进度。我的短板也在这里，细节上容易磨太久，整体节奏会被拖住；现在我会先交 80 分的版本，再回头改。

3. 刚学 C 语言那阵，我很会假装努力。视频一集不落，代码一行行照敲，跑通了就以为会了。换一道题，脑子还是空白。后来改成笨办法，关掉视频，先在纸上写清输入、输出和边界，再动手；报错一行行读，读不懂就把变量打印出来。有次为一个指针错查到凌晨两点，解决时没觉得多有成就感，只是困；第二天再碰到同类问题，我一眼就能看出来。

4. 大二我进了学院的预备实习。第一次写申报书，我自认为写得漂亮，交上去被老师一句「你的创新点在哪」问住。改到第四遍才像样，背景砍掉一半，方案拆成能验证的小步，预期成果写成能打勾的条目。那之后我写东西多了个标准，别人得能照着我的方案复核。

5. 后来跟着做家用语音监测的项目，我负责 APP 那端和联调。说起来两个词，做起来全是碎事，声音怎么画成曲线、误报多了阈值调到哪、WiFi 断了怎么重连。标阈值那几天，白天在实验室录样本，晚上回去改参数，第二天再测。数据稳下来的那天我没多激动，只觉得这样可以交了。

6. 暑假我一个人写了套图书管理系统，需求、结构、菜单、异常处理都得自己定，数据放在 SQL Server 里。最费时间的是想别人会怎么把它用坏，输入空的、编号重复、文件读到一半坏了。写到后面养成个习惯，交之前先当一次最不讲理的用户，能顶住才算完。

7. 公益课是最近做得最开心的事。给小学生讲物理，四十分钟里得让他们「哇」上三次，不然注意力就跑了。气球、纸杯、手电筒当道具，让他们自己上手，别听我念 PPT。有个男孩每节课都坐第一排，最后一次下课他问我「哥哥你下次还来吗」，我说来。

8. 剩下的时间给了羽毛球、骑车、游戏和记账。双打我打补位，已经习惯；沿黄河口能骑一下午，风大就低头蹬；游戏只玩策略类，想清楚再动手；账从大一开始记，记久了才知道钱花在哪。做事我有个笨习惯，Plan、Do、Done，计划拆到今天能动手，做的时候只看眼前这一步，做完必须留个结果，哪怕结果是「失败了，原因是这个」。我也把「结硬寨，打呆仗」写在便签上，遇到难事就先扎住，再一点点啃。

9. 「矢志向学」这四个字，我理解得很土，志是先想清楚往哪走，学是每天真把时间放进去。我算不上自律，但不想只在考试前使劲。读一遍手册、跑通一条链路、补一个边界，当下不加分，也没人看见；我心里清楚，今天多懂一层，明天换颗芯片就少慌一次。
