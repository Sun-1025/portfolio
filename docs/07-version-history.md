## 版本之间的关系

- v5 是当前视觉主体，v6 是交互层，不是一次完整的“换皮”。
- A1/A2/A3 都是在 v6 基线上的定点施工；A2 替换背景层，A3 只做布局和 Agent 气泡，不重新设计全站。
- CMS 改造与视觉施工并行，目标是让内容更新从“改 JSON”变成“卡片编辑”。
- 仓库整理不改变站点功能，只修文档、路径和隐私边界。
